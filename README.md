# DAIMIC Maintenance

Sistema demonstrativo de gestão integrada de manutenção e operações.

A demonstração inclui gestão de serviços, clientes, viaturas, equipa, stock, movimentos financeiros e relatórios dinâmicos. Os dados são fictícios e ficam guardados localmente no navegador através de `localStorage`; esta versão não possui autenticação nem base de dados partilhada.

## Identidade visual
O projecto utiliza os ficheiros `logo.jpg`, `banner.jpg` e `banner1.jpg` já presentes neste repositório.

## Publicação
